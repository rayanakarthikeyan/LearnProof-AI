# Third-party components

LearnProof's original code, documentation and course fixtures use the repository's MIT license. Dependencies retain their own licenses; MIT here does not relicense them.

- React and Vite: MIT. Their package metadata and notices are retained by dependency installation.
- Lucide icons: ISC.
- DM Sans and Manrope: SIL Open Font License 1.1, served locally through the pinned Fontsource packages. Their font-package LICENSE files are included by npm installation.
- FastAPI, pdfplumber, python-pptx and the Google GenAI SDK: see the pinned packages' own license metadata.
- LibreOffice: distributed separately under its project licenses; the optional container installs the official Debian packages rather than embedding a modified office distribution.
- FFmpeg: the imageio-ffmpeg distribution carries its own binary license/notices. Do not assume the repository MIT license covers the executable. The generated MP4 contains original authored educational content.
- Synthetic narration: generated using the installed Windows system speech engine; no impersonation or real student recording.

The code does not copy source from Academia-Lab or DS-Portal. The original problem-statement/brainstorming PDFs and user uploads are not redistributed in this repository. Preserve attribution for any additional course content you add to a submission.
